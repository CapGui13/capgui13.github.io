# Bridge DD · iPhone
Le site est généré par le workflow [bridge-dd.yml](../.github/workflows/bridge-dd.yml).
- Ouvrir https://capgui13.github.io/BridgeDD/
- Charger une donne via « Donne d'exemple… » ou importer un fichier PBN.
- Choisir le déclarant et le contrat, appuyer sur « Jouer la donne ».
- En mode entraînement, les résultats DDS par carte sont cachés jusqu'au coup.
- L'analyse montre les levées perdues par rapport au jeu double dummy optimal.
- Utiliser « Annuler » pour rejouer. Le mode Analyse affiche les indices à l'avance.
Moteur tiers : [DDS Web](https://github.com/dds-bridge/dds), licence maintenue dans le dossier distribué.
Limitations : nécessite le premier chargement HTTPS et l'isolation navigateur (coi-serviceworker) ; fonctionnement Safari réel non encore validé.
